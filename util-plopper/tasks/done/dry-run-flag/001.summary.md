# Dry flag implementation completed

Implemented global dry-run support for x-plopper:

- Added `--dry` and `--dry-run` CLI flags, including interactive mode support.
- Added shared `CommandContext` with virtual dry-run filesystem effects.
- Routed CLI config writes and machine processing writes through the context.
- Dry mode logs planned writes/directories and avoids real filesystem
  modifications.
- Updated help text, README version, package exports, and tests.
- Added focused coverage for `CommandContext` and `process_machine_file` dry-run
  behavior.
- Verified with `deno fmt --check`, `deno lint`, `deno test -A`, and
  `deno publish --dry-run --allow-dirty`.
