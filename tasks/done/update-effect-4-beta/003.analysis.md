# Effect 4 beta impact

Effect has no stable 4.x release: npm `latest` is 3.22.0 and `beta` is 4.0.0-beta.98. Updating from beta.94 to beta.98 type-checks gauth, internal-util, and util-xstate without production-code changes.

Beta.98 removed the old `Context.Tag` constructor still used by plopper's excluded example-template holder. Those declarations were migrated to the current `Context.Service<Self, Shape>()(key)` form. The published Effect-using packages are being minor-bumped: gauth 0.4.1 -> 0.5.0, internal-util 0.4.2 -> 0.5.0, and util-xstate 0.2.1 -> 0.3.0. Plopper is not bumped because its affected holder is excluded from publication.
